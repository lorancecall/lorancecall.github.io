두레공방 대표 개발자 소로안 (召路安)

이것저것 뜯어보는 컴퓨터 덕후의 취미 프로젝트 지도. Mac, Linux, Windows, 전자잉크 태블릿, 홈 서버. 요즘은 LLM 에이전트.

GitHub @lorancecall · 두레공방

  • 두레공방 내 컴퓨터들을 원격으로 쓰는 작업 환경을 만드는 작은 공방. 에이전트 자리도 조금. 큰 프로젝트는 여기서. · dureh-gb.github.io · github.com/dureh-gb
    • 두레 흩어진 내 컴퓨터들을 한 작업대에.
    • 마실 어디서든 내 컴퓨터로 마실. SSH 터미널, 화면, 파일.
    • 품앗이 건너편 컴퓨터에 손을 빌려주는 화면 스트리밍 도우미 (macOS · Linux · Windows).
  • reMarkable Paper Pro reMarkable의 미니멀한 느낌은 지키면서 소소한 기능 몇 가지를 더한 개인 애드온 모음. Paper Pro(OS 3.29)에서만 테스트했음. · 시작하기
    • rmpp-packages 기반: 설치 프로그램 rmpp setup과, 아래 애드온 모두가 올라가는 Vellum 패키지 저장소.
    • rmpp-lang 언어별 키보드와 폰트를 애드온으로. 한국어, 일본어, 중국어, 러시아어, ...
    • rmpp-textobj 텍스트 객체: 입력한 글자를 옮기고 고칠 수 있는 펜 획으로. T 메뉴에서.
    • rmpp-hwr 기기 안에서 도는 손글씨 인식. 올가미로 텍스트나 텍스트 객체로 (한국어, 영어, 중국어, 일본어, 라틴). 내 손글씨로 맞춤 모델 학습까지.
      • rmpp-hwr-dbCC BY 4.0 Paper Pro로 쓴 손글씨를 펜 획 그대로 모은 공개 데이터셋 (지금은 한국어와 영어).
    • rmpp-bt 블루투스 설정 화면과 키보드 지원.
    • rmpp-tailscale 설정 화면 속 Tailscale. 켜고 끄기, QR 로그인, 상태 확인, Tailscale 너머 SSH.
    • rmpp-refresh 노트 툴바에 전체 화면 새로고침 버튼 하나.
    • rmpp-studioPC PC에서 Paper Pro 튜토리얼 녹화·편집·내보내기. 손으로, 스크립트로, AI 에이전트로 SSH 원격 조작까지.
  • Legion Go & Windows 휴대용 PC 한 대를 든든하게.
    • keel 메모리, eGPU, 네트워크 지킴이를 하나로 (RAM Guard, eGPU Guard, net-pin 통합).
      • net-pin 인터넷, VPN 터널, 통신 경로를 내가 고른 네트워크에 고정. 킬 스위치 포함.
