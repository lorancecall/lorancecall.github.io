rmpp

reMarkable Paper Pro 애드온 모음. 내 언어로 입력, 손글씨를 텍스트로, 블루투스 키보드 연결, 어디서나 태블릿 접속. 내 태블릿에 맞춰 손본 코드. 자유롭게 사용.

들어 있는 것

모두 골라서 설치. xovi 필요 없음. 재부팅해도 그대로.

rmpp-lang

언어별 화면·하드웨어 키보드와 폰트. 한국어(옛한글 포함), 일본어, 중국어, 러시아어.

rmpp-hwr

태블릿 안에서 손글씨를 텍스트로. 몇 줄만 올가미로 고르거나 페이지 통째로. 한국어, 영어, 중국어, 일본어.

rmpp-bt

설정 속 블루투스 화면. 검색, 페어링, 연결, 삭제. 키보드는 Type Folio처럼.

rmpp-tailscale

설정 화면 속 Tailscale. 켜고 끄기, QR 로그인, 기기 목록, 어디서나 태블릿에 SSH.

rmpp-refresh

노트 툴바에 버튼 하나. 화면 전체를 다시 그려 잔상 제거.

rmpp-hwr-dbCC BY 4.0

Paper Pro로 쓴 공개 손글씨 데이터셋. 내 언어의 손글씨로 참여 가능.

시작하기

처음에는 15분쯤. 컴퓨터(Windows, macOS, Linux)와 태블릿 USB-C 케이블 필요.

  1. 개발자 모드 켜기

    설정 › 일반 › Paper Tablet › 소프트웨어 › 고급 › 개발자 모드.

    태블릿이 공장 초기화됨. 먼저 노트를 reMarkable 계정에 동기화. 다시 로그인하면 돌아옴. reMarkable의 개발자 모드 안내 참고.

  2. root 비밀번호 확인

    설정 › 일반 › 도움말 › 정보 › 저작권 및 라이선스. “일반 정보” 아래 SSH 비밀번호. 설치 앱이 처음 한 번만 묻고, 그다음부터는 키 사용.

  3. 태블릿 연결

    USB-C 케이블로 연결하면 태블릿 주소는 10.11.99.1. (Wi-Fi도 가능. SSH over Wi-Fi를 한 번 켜 두면 됨: ssh root@10.11.99.1 rm-ssh-over-wlan on)

  4. rmpp setup 실행

    내 시스템용 앱을 내려받고, 연결하고, 원하는 것을 체크한 뒤 설치. 설치 중 태블릿 화면이 한두 번 다시 시작됨.

    서명 없는 앱이라 Windows는 “Windows의 PC 보호” 창(추가 정보 › 실행), macOS는 시스템 설정 › 개인정보 보호 및 보안에서 허용 필요. 터미널이 편하면 설치 스크립트.

  5. reMarkable OS 업데이트 뒤

    rmpp setup을 다시 열고 복원. OS 업데이트가 애드온이 있는 시스템 파일을 바꾸기 때문. 설정과 노트는 그대로.

이용 조건

개인 프로젝트. 있는 그대로 공유.

개인용

내 태블릿에 맞춰 손본 코드. Vellum 패키지로 묶은 건 한곳에 모아 두려고.

공식 아님

Vellum 공식 저장소나 다른 패키지 목록에 직접 올릴 계획 없음.

가져가도 됨

쓸 만하면 다른 저장소나 패키지 관리자로 옮겨도 됨. 따로 묻지 않아도 됨. 라이선스(GPL-3.0)만 유지.

보장 없음

내 Paper Pro(OS 3.29)에서만 확인. 이슈는 환영, 수정은 시간 날 때.
